# FarCryCoop — тестовая сборка

Сборка из последнего коммита (`FarCryCoop\VERSION.txt`), собрана автоматически после пуша. Это не релиз: могут быть баги.

## Установка
1. Нужен Far Cry 1.4 из Steam.
2. Скопируйте папку `FarCryCoop` в `Mods` в папке Far Cry (`steamapps\common\FarCry\Mods`), разрешите замену. Больше никуда ничего класть не нужно.
3. Запуск — один из двух:
   - в Steam: свойства Far Cry → параметры запуска `-MOD:FarCryCoop` (так и «Присоединиться» в Steam запускает игру сразу с модом);
   - или в игре: меню «Mods» → FarCryCoop (игра перезапустится с модом).

Если от прошлых сборок в `Bin32` остались `FarCryCoopNet.asi` и `dinput8.dll` (ASI Loader), их можно удалить: они больше не нужны.

## Игра
- **Главное меню → Co-op.** Карта или сохранение, сложность, сколько игроков ждать, максимум игроков, кто может войти (все / друзья / по приглашению), пароль, выкладка оружия. «Launch» — игра начинается, лобби Steam создаётся само.
- **Player settings:** цвет рубашки и 4 оружия выкладки. Ник — имя Steam (русские буквы — латиницей: игра не показывает кириллицу).
- **Друзья заходят** кнопкой «Присоединиться к игре» в списке друзей Steam, по приглашению или через «Join by IP» (порт 49001). Если у игры пароль, игра сама его спросит.
- Обновить сборку: скопировать поверх новую. Удалить: папку `Mods\FarCryCoop`.
- Если папки `FarCryCoop\Steam` в архиве нет, сборка играет только по IP.

## Если что-то не так
Пришлите `log.txt` из папки Far Cry, файлы `netlog_*.txt` из `Mods\FarCryCoop` и `VERSION.txt`.
