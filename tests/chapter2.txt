# Chapter 2 in one session, as players would go through it: Research -> Treehouse -> Bunker ->
# Steam -> Regulator -> Control -> Rebellion, a listen host and one client. Research is where
# tests/chapter1.txt stops (it only arrives there), so its end is the first transition here. On
# every map: both are in with the same entities, every campaign checkpoint (CoopGoto) keeps them
# together, the client dies and respawns, the client sets off the mission end (the mission's own
# MissionFinished trigger, mission_<map>.xml), the exit zone opens and the host walking in changes
# the level for both. The places where one player could shut the other out are checked by their
# own scenarios (tests/softlock-*.txt; the chapter 2 survey is in docs/findings.md 2026-11-18).
# Checkpoints: CoopGoto puts the players 1 m apart along x, which put the client off the floor on
# Control checkpoint 3 every time (it fell through the map, the diff caught it mid-fall,
# runs/20261118-224430): the client is put on the checkpoint itself right after.
# The players are made immune as in tests/chapter1.txt (a GameRules.OnDamage wrapper of this test;
# the host stays immune while the client is killed: COOP_TestImmune=2).
# Run from the repo root: tools/bin/harness.exe test tests/chapter2.txt
up -mode host -map research -clients 1 -mod FarCryCoop -asi tools/bin/FarCryCoopNet.asi -start #COOP_ExpectPlayers=2;#CoopMap("research")
wait server players>=2 -t 60s
wait client1 players>=2 -t 120s
sleep 30s
lua server COOP_God=1 COOP_TestImmune=1 if GameRules.OnDamage ~= COOP_TestDmgFn then local old=GameRules.OnDamage COOP_TestDmgFn=function(self,hit) if COOP_TestImmune and hit.target and hit.target.type=="Player" and (COOP_TestImmune==1 or hit.target==_localplayer) then return end return %old(self,hit) end GameRules.OnDamage=COOP_TestDmgFn end


# ---- Research
expect-diff max=100000 missing=0
expect-diff max=1 class=^Player$
lua server CoopGoto(2) local c=_LastCheckPPos CoopMovePlayer(Harness:RemotePlayer(), {x=c.x,y=c.y,z=c.z+0.3})
sleep 10s
expect-diff max=1 class=^Player$
