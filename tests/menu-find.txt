# "Find game" (Co-op → Find game, MenuScreens/CoopFind.lua): the co-op games Steam lists, from the
# ASI (coop_steam find → CoopFind_List / CoopFind_Row), and "Join" (coop_steam joinlobby). One
# PC, one Steam account: the host's public lobby with a password, a second game in the menu finds
# it (the lock: pw 1) and joins it up to Game:Connect. The connection itself does not come up: Steam
# does not carry an account's packets to itself (the tunnel has its own test, steam-loop; the
# whole join needs a friend on another PC). Needs a logged-in Steam (-steam). The lobby is public
# for a minute (only this mod lists it).
# Run from the repo root: tools/bin/harness.exe test tests/menu-find.txt
up -mode host -map training -clients 1 -idle 1 -mod FarCryCoop -asi tools/bin/FarCryCoopNet.asi -steam -start #UI:ActivateScreen("Coop");#UI.PageCoop.GUI.WaitCombo:Select("1");#UI.PageCoop.GUI.MaxCombo:Select("6");#UI.PageCoop.GUI.DifficultyCombo:Select("Veteran");#UI.PageCoop.GUI.AccessCombo:SelectIndex(1);#UI.PageCoop.GUI.Password:SetText("abc");#UI.PageCoop.Launch()
wait server players>=1 -t 120s
expect-netlog server lobby.[0-9a-f]+.created.\(public,.6.players\) 30s
# the ASI marks the lobby up once the server holds its port (checked every 2 s)
sleep 5s
lua client1 UI:ActivateScreen("CoopFind")
expect-log client1 coop:.find.game:.[1-9][0-9]*.game 30s
expect-log client1 coop:.find.game:.[^|]+.\|.Training.\|.1/6.\|.Veteran.\|.pw.1 10s
expect client1 UI.PageCoopFind.Expected >= 1 => 1
# Join: the row of this host's game
lua client1 for i, g in UI.PageCoopFind.Games do if (g.Map == "Training") then UI.PageCoopFind.GUI.GameList:SelectIndex(i) end end UI.PageCoopFind.Join()
expect-netlog client1 in.lobby.[0-9a-f]+ 30s
# its server is up: the ASI connects the game through its tunnel
expect-netlog client1 run.#Game:Connect\("127.0.0.1:49011",1\) 30s
expect-no-events
down
