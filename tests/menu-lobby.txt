# With Steam on, "Launch" in the Co-op menu creates the Steam lobby by itself (it took
# "coop_steam host" in the console before): the access and the player limit chosen on the screen,
# the map in its data. Needs a logged-in Steam: -steam turns the ASI's Steam on for the run. The
# lobby is public for a minute (only games of this mod list it: lobby data fc1coop).
# Run from the repo root: tools/bin/harness.exe test tests/menu-lobby.txt
up -mode host -map training -clients 0 -mod FarCryCoop -asi tools/bin/FarCryCoopNet.asi -steam -start #UI:ActivateScreen("Coop");#UI.PageCoop.GUI.WaitCombo:Select("1");#UI.PageCoop.GUI.MaxCombo:Select("6");#UI.PageCoop.GUI.AccessCombo:SelectIndex(1);#UI.PageCoop.Launch()
wait server players>=1 -t 120s
expect-netlog server lobby.[0-9a-f]+.created.\(public,.6.players\) 30s
# the ASI marks the lobby up once the server holds its port (checked every 2 s)
sleep 5s
cmd server coop_steam find
expect-netlog server \|.Training.\|.1/6.\|.up=1 20s
expect-no-events
down
