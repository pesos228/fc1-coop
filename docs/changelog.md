**Подводные камни**
- Командная строка `FarCry.exe` ≤ 256 символов → всё передаётся через `boot.lua`.
- У пользователя `log_FileVerbosity=0`, харнес включает лог через `SystemCfgOverride.cfg`.
- `entity:GetPos()` возвращает переиспользуемый вектор, числа нужно копировать сразу.
- CryPak не читает zip-записи с data descriptor (Go `zip.Create`), нужен `CreateRaw` + Store.
- Python на Windows в текстовом режиме пишет CRLF и ломает правку Go-файлов. Лучше Edit или `newline=''`.
- Не запускать загрузку уровня из колбэка таймера (агент откладывает такие команды в `Hud:OnUpdate`).
- Бюджет пользователя: останавливаться при ~95% недельного лимита (`get_usage`).
