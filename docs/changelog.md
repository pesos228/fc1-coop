- Харнес `tools/harness` (Go, x86): `up/state/cmd/lua/wait/waitlog/log/events/shot/dump/diff/test/down`. Lua-агент `scripts/harness/agent.lua` переживает загрузки уровней (обёртки `Game.Load*` + `setglobal` на `_localplayer`). Супервизор бэкапит конфиги, ловит крэши, диалоги ошибок и зависания, снимает минидампы.
- Сценарии: `tests/training-basic.txt` (19/19 PASS, на исходном FarCryCoop падает в 3 местах), `tests/smoke-map.txt` (`MAP=<карта>`).
- Решение: **строим на FarCryCoop** (MIT). Клон в `external/FarCryCoop` (в `.gitignore`). ASI собирается из исходника (`tools\fcc\build-asi.cmd`), харнес внедряет его сам через `-asi`. Стартовые команды идут через `join_<pid>.txt` (иначе Treehouse/Swamp падают).
- Наши фиксы в клоне, ветка `heli-netpresence-at-spawn`, **не запушены**:
  - `0baaaa0`: вертолётам net presence сразу (было 6–38 м, стало ~1.5 м);
  - `3f7730d`: `COOP_ExpectPlayers` / `coop_expect N`, интро ждёт игроков;
  - `f838f1a`: выпавшее оружие спавнится у трупа (было 0,0,0 у клиента).
- Свой мод `FC1Coop` (`scripts/game/` → пак) с фиксом `helicommon.lua`. После перехода на FarCryCoop он не используется, но механизм сборки пака рабочий.
- Дымовой прогон всех 20 карт: все стартуют на двоих без крэшей; чисто на Regulator, Control, Volcano (`docs/maps.md`).

**Подводные камни**
- Командная строка `FarCry.exe` ≤ 256 символов → всё передаётся через `boot.lua`.
- У пользователя `log_FileVerbosity=0`, харнес включает лог через `SystemCfgOverride.cfg`.
- `entity:GetPos()` возвращает переиспользуемый вектор, числа нужно копировать сразу.
- CryPak не читает zip-записи с data descriptor (Go `zip.Create`), нужен `CreateRaw` + Store.
- Python на Windows в текстовом режиме пишет CRLF и ломает правку Go-файлов. Лучше Edit или `newline=''`.
- Не запускать загрузку уровня из колбэка таймера (агент откладывает такие команды в `Hud:OnUpdate`).
- Бюджет пользователя: останавливаться при ~95% недельного лимита (`get_usage`).
