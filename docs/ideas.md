## 2026-11-19

- **Понятная ошибка при другой версии мода** (сделано 2026-11-19: проверка в игре при подключении, сценарий `tests/version-check.txt`, подробности — `findings.md`, «Проверка версии мода»; версия — `COOP_VERSION` в `Scripts/COOP/Version.lua`). Сейчас игрок с другой версией подключается как ни в чём не бывало (в `INSTALL.md` только «у всех должна быть одна версия»). Набросок: версия мода одной строкой в Lua (и в ASI). Сервер шлёт её клиенту при подключении (`VER x`), клиент при несовпадении отключается с окном «у хоста версия X, у вас Y». Ещё можно показывать версию в списке Find game (данные лобби Steam) и не давать войти в чужую версию оттуда. Клиенты без обработчика `VER` (текущие) не отреагируют, проверка заработает начиная со следующей версии.
- **Самообновление.** Лаунчера больше нет (убран 2026-11-19, всё в меню игры), так что обновляться должен сам мод. Набросок: ASI при старте игры спрашивает последний релиз на GitHub нашего форка, меню показывает «есть версия X» и по кнопке скачивает архив и заменяет папку `Mods/FarCryCoop` (свою `CryGame.dll` в ней можно заменить только после выхода из игры: маленький помощник или замена при следующем запуске). Источник — только наши релизы. Версия одна: `COOP_VERSION` (`Scripts/COOP/Version.lua`).
- **Голосовой чат.** Сделан 2026-11-19 (`asi/voice.c`, `findings.md`). Дальше: громкость в Options → Sound, режим «по голосу» без клавиши, позиционный звук (тише издалека).
