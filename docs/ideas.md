## 2026-11-19

- **Понятная ошибка при другой версии мода** (в работе с 2026-11-19, сценарий `tests/version-check.txt`). Сейчас игрок с другой версией подключается как ни в чём не бывало (в `INSTALL.md` только «у всех должна быть одна версия»). Набросок: версия мода одной строкой в Lua (и в ASI). Сервер шлёт её клиенту при подключении (`VER x`), клиент при несовпадении отключается с окном «у хоста версия X, у вас Y». Лаунчер сравнивает версии ещё в лобби (поле в JSON лобби, `launcher/src/lobby.rs`). Клиенты без обработчика `VER` (текущие) не отреагируют, проверка заработает начиная со следующей версии.
- **Самообновление.** Лаунчер при старте проверяет последний релиз на GitHub нашего форка и предлагает скачать архив, заменить `Mods/FarCryCoop`, `Bin32` (ASI) и себя, затем перезапуститься. Источник — только наши релизы. Версия лаунчера сейчас 0.1.0 (`tauri.conf.json`), мода — 0.3 beta (`release/INSTALL.md`), их нужно свести к одной.
- **Голосовой чат.** У нас уже есть Steam (`steam/FarCryCoopSteam.c`: `ISteamUser`, `ISteamNetworkingMessages`). Голос через Steam Voice (`StartVoiceRecording` / `GetVoice` / `DecompressVoice`) отдельным каналом сообщений участникам сессии, вывод через `waveOut`, клавиша push-to-talk. Задача большая. Пока её нет, остаются Steam-чат или Discord.
