# Ожидание игроков, общий старт и пропуск катсцен

Статус: **черновик**, идея владельца (2026-10-28), по образцу Synergy. Не начато. Пункты «Предложение» ждут подтверждения владельца.

## Как должно быть в игре

1. **Минимум игроков.** Хост при создании сервера задаёт, сколько игроков нужно для старта (`coop_minplayers N`, в лаунчере — поле при создании сервера).
2. **Ожидание.** Пока не набралось N загрузившихся игроков, никто не заспавнен. Каждый, кто уже загрузился, видит виды карты (камера переключается между точками уровня) и надпись «Ждём игроков: 2 из 3».
3. **Общий старт.** Как только загрузился последний из N, все одновременно спавнятся в одной точке (старт карты), и у всех сразу начинается стартовая катсцена.
4. **Пропуск катсцен голосованием.** Во время катсцены игрок может проголосовать за пропуск; когда «за» больше половины игроков, катсцена пропускается у всех. На экране видно, сколько проголосовало.

## Решения, которые нужно подтвердить

| Вопрос | Предложение |
|---|---|
| Что если кто-то не грузится (вылетел, медленный ПК)? | Таймаут ожидания (по умолчанию 2 мин, `coop_minplayers_timeout`), после него старт с теми, кто есть. Хост может стартовать раньше командой `coop_start`. |
| Откуда точки для видов карты? | Камеры, которые уже есть на уровне (`CameraSource` из катсцен), плюс точки спавна; если их нет — облёт вокруг точки старта. |
| Игрок, который пришёл после старта | Спавнится рядом с живым товарищем; катсцена, если идёт, у него не стартует с середины (сразу в игру). |
| Как голосовать за пропуск? | Та же клавиша, что пропускает катсцену в одиночной игре; повторное нажатие отменяет голос. |
| «Больше половины» при 2 игроках | Строго больше половины: при 2 игроках нужны оба, при 3 — двое, при 4 — трое. |
| Пропускать только стартовую катсцену или все? | Все катсцены карты (стартовые и в середине). |
| Хост может пропустить без голосования? | Нет, только голосование (одинаково для всех). |

## Что уже есть

- `COOP_ExpectPlayers` / `coop_expect N` (наш фикс в FarCryCoop): стартовое интро ждёт N игроков, максимум 90 с. Это основа пунктов 1 и 3.
- `CoopMovePlayer`: телепорт игрока, которому сервер доверяет (для общего спавна в одной точке).
- Последовательности (катсцены) сервер пересылает клиентам при старте (`SEQ`).

## Что выяснить до реализации

- Как в одиночной игре пропускается катсцена (какая клавиша, какой вызов в скриптах/`Movie`) и можно ли так же остановить её у всех клиентов.
- Можно ли держать игрока без спавна (наблюдатель) в режиме `COOP` и как переключать его камеру между точками.

## Как проверяем (харнес)

- `tests/lobby.txt`: хост + 2 клиента, `coop_minplayers 3`. Пока не подключился второй клиент, ни один игрок не заспавнен, а на экране надпись ожидания (скриншот). После подключения у всех троих в логе `sequence first_cutscene` в пределах 1 с, игроки в одной точке (`diff` игроков ≤ 0.5 м после катсцены).
- `tests/cutscene-skip.txt`: 3 игрока, голосуют двое → катсцена остановлена у всех; голосует один → идёт дальше.
- Таймаут: `coop_minplayers 3` и только 2 игрока → старт через таймаут.
